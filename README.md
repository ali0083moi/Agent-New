# پیگیر — منشی شخصی و هم‌پای پیگیر تو 🤝

«پیگیر» یک ایجنت هوش مصنوعی شخصی است که کلاس‌ها، تکلیف‌ها، کارها و ددلاین‌هایت را می‌شناسد، **خودش پیگیرت می‌شود**، برایت برنامه می‌ریزد، می‌گوید «می‌رسی بری بیرون یا نه» و آخر هفته برایت گزارش می‌نویسد؛ همه‌اش هم فقط با حرف زدن (متن یا ویس)، هم در **تلگرام** و هم در **رابط وب**، که با هم همگام‌اند.

## چه کارهایی می‌کند؟

| قابلیت | توضیح |
|---|---|
| 🗓 شناخت برنامه ثابت | کلاس‌های دانشگاه، کلاس زبان، شیفت کاری… («سه‌شنبه و پنجشنبه ۶ تا ۸ شب کلاس زبان دارم»). پشتیبانی از هفته‌های **فرد/زوج** دانشگاه. |
| 📷 خواندن عکس برنامه کلاسی | عکس برنامه دانشگاه را بفرست؛ همه کلاس‌ها را استخراج و ثبت می‌کند و فقط می‌پرسد چیزی اشتباه است یا نه. |
| 📝 بعد از هر کلاس | چند دقیقه بعد از پایان کلاس می‌پرسد «تکلیف چی دادن؟»، تکلیف‌ها را با ددلاینِ «جلسه بعد» ثبت می‌کند و تا آن موقع پیگیر است. |
| ⏰ پیگیری ددلاین‌ها | یادآوری قبل از ددلاین (۲۴ و ۳ ساعت قبل در حالت معمولی)، پیگیری وسط کار برای کارهای طولانی، و سؤال بعد از گذشتن ددلاین. |
| 🧭 برنامه‌ریزی هوشمند | ۷-۸ کار با ددلاین‌های مختلف؟ بر اساس ددلاین، اولویت، کلاس‌ها، ساعت کاری و سقف تمرکز روزانه بلوک‌های کاری می‌چیند و اگر به چیزی نرسی، صریح هشدار می‌دهد. |
| 🔎 «می‌رسم برم بیرون؟» | فقط تداخل با کلاس را نمی‌بیند؛ **حجم کل کارها و وقت آزاد تا ددلاین‌ها** را حساب می‌کند. ممکن است آن ساعت خالی باشد ولی آن‌قدر کار داشته باشی که نرسی. |
| ⏱ چک کردن کار | سر بلوک‌های کاری می‌پرسد «شروع کردی؟»، تایمر تمرکز، آخر بلوک می‌پرسد چقدر پیش رفتی، وقتی چند ساعت خبری ازت نیست احوال می‌پرسد. |
| 📊 کار مفید | ساعت کار مفید روزانه/هفتگی، به تفکیک حوزه (کار، دانشگاه، زبان…)، مقایسه با هدف روزانه. |
| ☀️🌙 روتین روزانه | صبح برنامه امروز را می‌فرستد، شب جمع‌بندی می‌کند و می‌پرسد کار دیگری هم کرده‌ای که ثبت نشده. |
| 📄 گزارش هفتگی | دو نسخه: **گزارش رسمی برای کارفرما** (فقط کارهای کاری) و **مرور شخصی** صادقانه. هر هفته خودکار در تلگرام می‌آید (قابل فوروارد) و در وب قابل کپی/دانلود است. |
| 🧠 حافظه | چیزهایی که درباره‌ات می‌گویی (کارت، اهدافت مثل آیلتس، عادت‌هایت) را به خاطر می‌سپارد. |
| 🎙 ویس | در تلگرام یا وب ویس بفرست؛ به متن تبدیل و اجرا می‌شود. |
| 🔄 همگام‌سازی | یک گفتگوی واحد: هر چه در تلگرام بگویی در وب هست و برعکس (پیام‌های وب هم در تلگرام نشان داده می‌شوند). |

## نمونه گفتگو

```
تو:     سه‌شنبه و پنجشنبه‌ها ساعت ۶ تا ۸ شب کلاس آیلتس دارم. هدفم ۷ـه تا آخر اسفند
پیگیر:  ✅ ثبت شد: کلاس آیلتس — سه‌شنبه و پنجشنبه ۱۸:۰۰ تا ۲۰:۰۰ 🎯 هدف: آیلتس ۷ تا ۲۹ اسفند
        بعد از هر جلسه ازت می‌پرسم چه تکلیفی دادن.

(سه‌شنبه ۲۰:۱۵ در تلگرام)
پیگیر:  کلاس آیلتس تموم شد 👀 برای پنجشنبه تکلیف چی دادن؟   [تکلیفی نداشتیم] [کلاس نرفتم]
تو:     یه رایتینگ تسک ۲ درباره محیط زیست
پیگیر:  ✅ ثبت شد — تا پنجشنبه ۱۸:۰۰. فردا ساعت ۱۰ یه بلوک یک‌ساعته براش گذاشتم.

تو:     پنجشنبه ۴ تا ۷ دوستم گفته بریم بیرون، می‌رسم؟
پیگیر:  آره ولی فشرده می‌شه 😅 ساعت ۱۸ کلاس داری و تمرین پایگاه داده (۲ ساعت) تا شنبه ددلاین داره…
```

## راه‌اندازی

### ۱) پیش‌نیازها
- کلید API از [GapGPT](https://gapgpt.app/platform-v2/docs/quickstart) (سازگار با OpenAI)
- یک ربات تلگرام از [@BotFather](https://t.me/BotFather) (اختیاری ولی توصیه‌شده)
- Docker، یا Python 3.11+ و Node 20+

### ۲) تنظیمات
```bash
cp .env.example .env
# حداقل این‌ها را پر کن:
#   GAPGPT_API_KEY=sk-...
#   TELEGRAM_BOT_TOKEN=123456:ABC...
#   APP_PASSWORD=...   (اگر روی سرور اجرا می‌کنی)
```
فایل `.env` در git نادیده گرفته می‌شود؛ کلیدها را هیچ‌وقت commit نکن.

### ۳الف) اجرا با Docker (ساده‌ترین)
```bash
docker compose up -d --build
```
بعد برو به `http://localhost:8000`. داده‌ها در پوشه `data/` می‌مانند.

### ۳ب) اجرای دستی
```bash
make install     # venv پایتون + npm install
make run         # بیلد رابط وب و اجرای سرور روی پورت 8000
```
برای توسعه: `make dev-backend` و در ترمینال دیگر `make dev-frontend` (آدرس `http://localhost:5173`).

### ۴) اتصال تلگرام
1. در `.env` مقدار `TELEGRAM_BOT_TOKEN` را بگذار و سرور را اجرا کن.
2. در وب به **تنظیمات ← تلگرام** برو؛ یک کد اتصال می‌بینی (در لاگ سرور هم چاپ می‌شود).
3. به ربات بفرست: `/start 123456` — تمام! از این به بعد فقط تو می‌توانی با ربات حرف بزنی.

> **سرور داخل ایران؟** `api.telegram.org` از داخل ایران فیلتر است. یا سرور را خارج از ایران اجرا کن، یا `TELEGRAM_PROXY` (مثلاً `socks5://127.0.0.1:1080`) یا یک Bot API واسط در `TELEGRAM_API_BASE` تنظیم کن.

دستورهای ربات: `/today` برنامه امروز · `/tasks` کارهای باز · `/plan` برنامه‌ریزی · `/stats` آمار · `/report` گزارش هفتگی · `/stop` توقف تایمر. البته لازم نیست؛ هر چیزی را عادی بنویس.

### ۵) شروع
اولین کارها:
- عکس برنامه کلاسی دانشگاهت را بفرست.
- بگو کلاس زبانت کِی است و هدفت چیست.
- از کارت بگو (کجا کار می‌کنی، کارفرما کیست) تا گزارش هفتگی درست ساخته شود.
- در تنظیمات ساعت خواب/بیداری و بازه کاری‌ات را تنظیم کن (پیام‌ها در ساعت خواب ارسال نمی‌شوند).

## انتخاب مدل‌ها
همه مدل‌ها از `.env` قابل تغییرند (فهرست کامل در [صفحه قیمت GapGPT](https://gapgpt.app/platform-v2/pricing)):

| متغیر | کاربرد | پیش‌فرض |
|---|---|---|
| `CHAT_MODEL` | گفتگو، ابزارها، برنامه‌ریزی، گزارش | `gpt-4.1` |
| `FAST_MODEL` | نوشتن پیام‌های پیگیری خودکار | `gpt-4.1-mini` |
| `VISION_MODEL` | خواندن عکس برنامه کلاسی | `gpt-4.1` |
| `TRANSCRIBE_MODEL` | تبدیل ویس به متن | `whisper-1` |

مدل گفتگو باید **function calling** را پشتیبانی کند. با دکمه «تست اتصال» در تنظیمات می‌توانی اتصال را امتحان کنی.

## معماری

```
                    ┌──────────── FastAPI (backend/app) ────────────┐
 تلگرام ⇄ telegram.py ─┐                                             │
                       ├─► agent/core.py ── GapGPT (OpenAI-compatible)│
 وب (React) ⇄ api/ ────┘     │  ابزارها: agent/tools.py (۲۸ ابزار)    │
      ▲   SSE (bus.py)       ▼                                        │
      └──────────────── SQLite (db.py) ◄── planner.py  stats.py       │
                             ▲             reports.py  cal.py         │
           scheduler ── agent/proactive.py ◄── followups.py           │
                    └─────────────────────────────────────────────────┘
```

- **یک گفتگوی مشترک:** همه پیام‌ها (وب، تلگرام، پیام‌های خودکار) در یک جدول ذخیره می‌شوند و از طریق SSE زنده به وب می‌رسند.
- **ایجنت:** هر پیام با یک system prompt شامل تاریخ شمسی/میلادی، تقویم ۱۴ روز آینده، کلاس‌ها، کارهای باز، حافظه و برنامه امروز به مدل داده می‌شود و مدل با ابزارها داده‌ها را تغییر می‌دهد.
- **موتور پیگیری** (`followups.py`): هر ۳۰ ثانیه پیگیری‌های لازم را (با کلید یکتا، بدون تکرار) می‌سازد، قبل از ارسال دوباره اعتبارشان را چک می‌کند (مثلاً اگر کار انجام شده یا ددلاین عوض شده، لغو می‌شود) و ساعت خواب را رعایت می‌کند.
- **برنامه‌ریز** (`planner.py`): زمان آزاد = بازه کاری منهای کلاس‌ها (با زمان رفت‌وآمد) و رویدادها، با سقف تمرکز روزانه؛ چیدن کارها به روش «اول زودترین ددلاین» (EDF) که برای امکان‌پذیری بهینه است؛ و بررسی «می‌رسم؟» با مقایسه امکان‌پذیری ددلاین‌ها با و بدون آن بازه زمانی.

## تست
```bash
make test
```
تست‌ها (۴۳ مورد) تاریخ شمسی، کلاس‌های فرد/زوج، برنامه‌ریز، بررسی وقت آزاد، موتور پیگیری (بعد از کلاس، ددلاین، ساعت خواب، بلوک‌های کاری)، حلقه ایجنت با یک LLM ساختگی، ربات تلگرام (اتصال، دکمه‌های پاسخ سریع) و API وب را پوشش می‌دهند.

## امنیت و حریم خصوصی
- همه داده‌ها روی سرور خودت در `data/peygir.db` (SQLite) می‌مانند.
- ربات تلگرام فقط به حسابی که با کد اتصال وصل شده جواب می‌دهد.
- برای اجرا روی اینترنت حتماً `APP_PASSWORD` و یک `SECRET_KEY` تصادفی بگذار و ترجیحاً پشت HTTPS (مثلاً Caddy/Nginx) اجرا کن.
