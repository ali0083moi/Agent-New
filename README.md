# پیگیر — منشی شخصی و هم‌پای پیگیر تو 🤝

«پیگیر» یک ایجنت هوش مصنوعی شخصی است که کلاس‌ها، تکلیف‌ها، کارها، عادت‌ها و ددلاین‌هایت را می‌شناسد، **خودش پیگیرت می‌شود**، برایت برنامه می‌ریزد، می‌گوید «می‌رسی بری بیرون یا نه»، مربی آیلتست است و آخر هفته برایت گزارش می‌نویسد. همه‌اش هم فقط با حرف زدن (متن یا ویس)، هم در **تلگرام** و هم در **رابط وب/اپ گوشی**، که با هم همگام‌اند.

## قابلیت‌ها

### برنامه و کارها
- **برنامه ثابت:** کلاس‌های دانشگاه، کلاس زبان، شیفت کاری؛ با پشتیبانی از هفته‌های **فرد/زوج**.
- **عکس برنامه کلاسی:** عکس را بفرست، همه کلاس‌ها ثبت می‌شوند.
- **فوروارد و فایل:** پیام فورواردشده از گروه کلاس یا PDF سرفصل/تکلیف را بفرست؛ تکلیف‌ها، امتحان‌ها و ددلاین‌ها خودکار استخراج می‌شوند.
- **بعد از هر کلاس:** می‌پرسد «تکلیف چی دادن؟»، ددلاین را «جلسه بعد» می‌گذارد و تا آن موقع پیگیر است.
- **پروژه‌های بزرگ:** خودکار به زیرکار و مرحله با ددلاین میانی شکسته می‌شوند.
- **امتحان‌ها:** برنامه‌ریزی برعکس از تاریخ امتحان (مطالعه هر فصل + مرور نهایی).
- **برنامه‌ریز هوشمند:**
  - اول کاری را می‌چیند که ددلاینش زودتر است (EDF).
  - کلاس‌ها، رفت‌وآمد و سقف تمرکز روزانه را رعایت می‌کند.
  - **کارهای عمیق را در ساعت‌های اوج تمرکزت** می‌گذارد (از روی سابقه‌ات یاد می‌گیرد).
  - **خطای تخمینت را یاد می‌گیرد**، مثلاً «رایتینگ‌هات ۱.۵ برابر طول می‌کشن».
  - هر وقت کاری عوض شود یا بلوکی از دست برود، دوباره برنامه می‌ریزد.
  - بلوک‌هایی را که خودت جابه‌جا کرده‌ای سر جایشان نگه می‌دارد.
- **«می‌رسم برم بیرون؟»:** فقط تداخل با کلاس را نگاه نمی‌کند؛ می‌سنجد با حجم کارهایت تا ددلاین‌ها وقت کافی می‌ماند یا نه.
- **حالت نجات:** وقتی عقب افتادی، می‌گوید به کدام ددلاین نمی‌رسی و چند ساعت کم داری. پیشنهاد می‌دهد چه چیزی عقب بیفتد، روزی چقدر بیشتر کار کنی، یا متن درخواست تمدید از استاد/مدیر را برایت می‌نویسد.

### پروژه‌ها و اپلای
- **پروژه‌ها با اسم مستعار:** مثلاً «tahami supercars» = «پروژه ماشین». کار، زمان کار و گزارش به پروژه وصل می‌شوند و هر اسمی بگویی می‌فهمد.
- **گزارش هفتگی جدا برای هر پروژه**، برای وقتی هر پروژه کارفرمای خودش را دارد.
- **پیگیری استادها (اپلای):** لیست استادها با وضعیت (باید ایمیل بزنم ← فرستادم ← جواب داد ← مصاحبه). اگر چند روز جوابی نیامد، یادآوری می‌کند که follow-up بفرستی.

### پیگیری
- یادآوری قبل از ددلاین، پیگیری وسط کار، و سؤال بعد از گذشتن ددلاین.
- «شروع کردی؟» سر بلوک کاری و «چقدر پیش رفتی؟» آخرش؛ احوال‌پرسی وقتی چند ساعت خبری ازت نیست.
- **صبح:** برنامه امروز و پرسیدن قول امروز (مثلاً «۲ ساعت رایتینگ»). **شب:** جمع‌بندی، بررسی قول‌ها و عادت‌ها.
- **جلسه برنامه‌ریزی هفتگی** (پیش‌فرض جمعه عصر) برای چیدن هفته بعد.
- دکمه **«⏰ یک ساعت دیگه»** زیر هر یادآوری.
- **یادآوری‌های تطبیقی:** یاد می‌گیرد کدام یادآوری‌ها بی‌جواب می‌مانند و زمان و تعدادشان را تنظیم می‌کند.
- ساعت خوابت را رعایت می‌کند.

### عادت‌ها، امتیاز و آمار
- عادت‌ها (ورزش، مطالعه، خواب…) با شمارش روزهای پشت‌سرهم 🔥 و یادآوری.
- **امتیاز، سطح و نمره هفتگی** (از کار مفید، ددلاین‌های به‌موقع، قول‌ها و عادت‌ها).
- نقشه حرارتی یک‌ساله کار مفید، نمودار ساعت‌های اوج، آمار روزانه و هفتگی به تفکیک حوزه.
- **گزارش هفتگی:** نسخه رسمی برای کارفرما (فقط کارهای کاری) + مرور شخصی صادقانه.

### مربی آیلتس 🎓
- **تصحیح رایتینگ** (Task 1/2) با معیارهای رسمی: نمره هر معیار، اصلاح جمله‌ها، لغت جدید. عکس رایتینگ دست‌نویس هم قبول است.
- **تمرین اسپیکینگ:** سؤال/کیوکارت می‌دهد، با ویس جواب می‌دهی، بازخورد و نمره می‌گیری.
- **مرور لغت با جعبه لایتنر:** هر روز در تلگرام و فلش‌کارت در وب.
- نمودار پیشرفت هر مهارت نسبت به نمره هدف و شمارش معکوس تا آزمون.

### حافظه و هوش
- **حافظه بلندمدت:** پیام‌های قدیمی با جستجوی معنایی (embedding) پیدا می‌شوند. گفتگوهای قدیمی خلاصه می‌شوند. بعد از هر گفتگو نکته‌های ماندگار درباره تو خودکار یاد گرفته می‌شود.
- **برگردون ↩️:** هر تغییری که ایجنت داده با یک دکمه برمی‌گردد. قبل از حذف کردن هم همیشه تأیید می‌گیرد.
- **مدل جایگزین:** اگر مدل اصلی GapGPT جواب نداد، خودکار سراغ مدل بعدی می‌رود.
- **کنترل هزینه:** مصرف توکن و هزینه هر روز و هر مدل نمایش داده می‌شود و می‌توانی **سقف بودجه روزانه** بگذاری.

### رابط و اعلان‌ها
- تلگرام: جواب‌ها **زنده و تدریجی** نوشته می‌شوند، **جواب صوتی (TTS)** دارد، و تحویل پیام‌ها **با تلاش مجدد** است.
- وب: فارسی و راست‌به‌چپ، تاریخ شمسی با انتخابگر تاریخ شمسی، حالت تیره.
- **برنامه هفتگی قابل کشیدن:** بلوک‌ها و رویدادها را جابه‌جا کن یا اندازه‌شان را عوض کن؛ با زدن روی جای خالی چیزی اضافه کن. **نمای ماهانه** هم دارد.
- **نصب روی گوشی (PWA) و نوتیفیکیشن مرورگر:** جایگزین وقتی تلگرام در دسترس نیست.

## راه‌اندازی

### ۱) پیش‌نیازها
- کلید API از [GapGPT](https://gapgpt.app/platform-v2/docs/quickstart)
- یک ربات تلگرام از [@BotFather](https://t.me/BotFather)
- Docker، یا Python 3.11+ و Node 20+

### ۲) تنظیمات
```bash
cp .env.example .env
#   GAPGPT_API_KEY=sk-...
#   TELEGRAM_BOT_TOKEN=123456:ABC...
#   APP_PASSWORD=...   (اگر روی سرور اجرا می‌کنی)
```
فایل `.env` در git نادیده گرفته می‌شود؛ کلیدها را هیچ‌وقت commit نکن.

### ۳الف) اجرا با Docker
```bash
docker compose up -d --build
```
بعد برو به `http://localhost:8000`. داده‌ها در پوشه `data/` می‌مانند.

### ۳ب) اجرای دستی
```bash
make install     # venv پایتون + npm install
make run         # بیلد رابط وب و اجرای سرور روی پورت 8000
```
برای توسعه: `make dev-backend` و در ترمینال دیگر `make dev-frontend` (آدرس `http://localhost:5173`).

### ۴) اتصال تلگرام
1. سرور را با `TELEGRAM_BOT_TOKEN` اجرا کن.
2. در وب به **تنظیمات ← تلگرام** برو و کد اتصال را بردار (در لاگ سرور هم چاپ می‌شود).
3. به ربات بفرست: `/start 123456`. از این به بعد فقط تو می‌توانی با ربات حرف بزنی.

دستورها: `/today` `/tasks` `/plan` `/stats` `/habits` `/ielts` `/vocab` `/report` `/undo` `/stop`. لازم هم نیست؛ هر چیزی را عادی بنویس یا ویس بفرست.

### ۵) استقرار خودکار با هر push (CI/CD)
هر push در GitHub Actions اول تست‌ها و بیلد رابط وب را اجرا می‌کند (`.github/workflows/ci.yml`). اگر روی برنچ اصلی بود و همه سبز شد، Actions با SSH به سرور وصل می‌شود و `deploy/docker-deploy.sh` را اجرا می‌کند:
1. کد جدید را در همان پوشه نصب Docker روی سرور می‌گذارد. کد از خود Actions فرستاده می‌شود، پس سرور لازم نیست به GitHub دسترسی داشته باشد.
2. از دیتابیس **پشتیبان** می‌گیرد (۱۵ تای آخر در `data/backups`).
3. ایمیج را دوباره بیلد می‌کند و کانتینر را از نو می‌سازد.
4. صبر می‌کند تا **نسخه جدید** جواب بدهد. اگر بالا نیامد، **خودکار به ایمیج قبلی برمی‌گردد** و اجرای Actions قرمز می‌شود. اگر بیلد خطا بدهد، نسخه در حال اجرا اصلاً دست نمی‌خورد.
5. بعد از هر نصب موفق، پیام «🚀 نسخه جدید نصب شد» در تلگرام می‌آید. نسخه فعلی پایین منوی وب نوشته شده است.

`.env`، پوشه `data/` و `docker-compose.yml` ویرایش‌شده روی سرور حفظ می‌شوند. تغییرات دستی دیگر روی فایل‌های کد در `.deploy/local-changes-*.patch` ذخیره و بعد با کد جدید جایگزین می‌شوند.

**راه‌اندازی (یک بار):** در GitHub برو به **Settings ← Secrets and variables ← Actions ← New repository secret** و این‌ها را اضافه کن:

| Secret | مقدار |
|---|---|
| `DEPLOY_HOST` | آی‌پی یا دامنه سرور |
| `DEPLOY_PORT` | پورت SSH (پیش‌فرض 22) |
| `DEPLOY_USER` | کاربر SSH (پیش‌فرض `root`) |
| `DEPLOY_SSH_KEY` | کلید خصوصی SSH (پیشنهادی) — یا به‌جایش `DEPLOY_PASSWORD` |
| `DEPLOY_KNOWN_HOSTS` | اختیاری: خروجی `ssh-keyscan -p <port> <host>` تا هویت سرور چک شود |
| `DEPLOY_PATH` | اختیاری: پوشه پروژه روی سرور. اگر نگذاری، از روی کانتینر فعلی پیدا می‌شود. روی سرور خالی `/opt/Agent-New` است. |

بعد از آن هر push خودکار نصب می‌شود. برای نصب دوباره همان نسخه، در تب **Actions** روی **Run workflow** بزن. تا وقتی این secretها نباشند، مرحله deploy با یک هشدار رد می‌شود و بقیه CI کار می‌کند.

ساخت کلید SSH مخصوص deploy:
```bash
ssh-keygen -t ed25519 -f deploy_key -N ""           # روی کامپیوتر خودت
ssh-copy-id -i deploy_key.pub -p <port> root@<host>   # کلید عمومی روی سرور
# محتوای فایل deploy_key را در secret به نام DEPLOY_SSH_KEY بگذار
```

برای دامنه و HTTPS، یک reverse proxy (Caddy یا nginx) جلوی پورت کانتینر بگذار.

### ⚠️ کجا اجرا کنم؟ (تلگرام و GapGPT)
- `api.telegram.org` از **داخل ایران** فیلتر است.
- GapGPT روی CDN ایرانی (آروان) است و ممکن است اتصال از **سرورهای خارج از ایران** را قبول نکند (از محیط تست ما قبول نکرد).

راه‌حل‌ها:
1. **سرور داخل ایران** + `TELEGRAM_PROXY` (مثلاً `socks5://127.0.0.1:1080`) یا یک Bot API واسط در `TELEGRAM_API_BASE`.
2. **سرور خارج** + `LLM_PROXY` روی یک پروکسی داخل ایران برای رسیدن به GapGPT.
3. اگر تلگرام در دسترس نبود، **نوتیفیکیشن مرورگر (PWA)** جایگزین است. برای این کار سایت باید روی HTTPS باشد.

## انتخاب مدل‌ها
همه مدل‌ها در `.env` یا **تنظیمات ← هوش مصنوعی** قابل تغییرند. پیشنهادهای اولیه از لیست GapGPT در جدول زیر آمده (قیمت به دلار برای هر ۱ میلیون توکن ورودی/خروجی):

| نقش | کاندیدها |
|---|---|
| گفتگو و ابزارها (`CHAT_MODEL`) | `gpt-4.1` ($2/$8)، `claude-sonnet-5-5` ($2/$10)، `gpt-6-sol` ($2/$10)؛ ارزان‌تر: `gpt-5.4-mini`، `gemini-3.5-flash` |
| پیام‌های خودکار، خلاصه و یادگیری (`FAST_MODEL`) | `gpt-4.1-mini`، `gpt-6-luna` یا `claude-haiku-5-5` ($0.10/$0.50) |
| تصویر (`VISION_MODEL`) | `gpt-4.1`، `gemini-3.5-flash`، `claude-sonnet-5-5` |
| تصحیح آیلتس (`IELTS_MODEL`) | `claude-opus-5-5` ($4/$20) یا همان مدل گفتگو |
| ویس / صدا / حافظه | `gapgpt/whisper-1`، `gpt-4o-mini-tts`، `text-embedding-3-small` |

### مقایسه واقعی مدل‌ها (eval)
۱۰ سناریوی واقعی را روی چند مدل اجرا کن و امتیاز، زمان و هزینه هر کدام را ببین. سناریوها:
- تکلیف بعد از کلاس
- «می‌رسم برم بیرون؟»
- برنامه‌ریزی ۵ کار
- تاریخ شمسی
- خواندن عکس برنامه کلاسی
- تأیید قبل از حذف
- تصحیح رایتینگ
- ثبت عادت
- برنامه امتحان
- گپ ساده

```bash
cd backend
.venv/bin/python -m app.evals --models gpt-4.1,claude-sonnet-5-5,gemini-3.5-flash,gpt-5.4-mini
# خروجی: evals-report.md (جدول مقایسه) و evals-report.json (جزئیات)
```

## تست
```bash
make test
```
همین تست‌ها روی هر push در GitHub Actions هم اجرا می‌شوند.
۸۵ تست خودکار این بخش‌ها را پوشش می‌دهند:
- تاریخ شمسی و هفته‌های فرد/زوج
- برنامه‌ریز، تخمین یادگرفته‌شده، ساعت اوج، زیرکارها، برنامه امتحان، حالت نجات
- موتور پیگیری (بعد از کلاس، ددلاین، ساعت خواب، تعویق، یادآوری تطبیقی، عادت، لغت، برنامه‌ریزی هفتگی)
- حافظه معنایی، خلاصه‌سازی و استخراج نکته
- برگرداندن تغییرات و تأیید قبل از حذف
- آیلتس و جعبه لایتنر
- لایه LLM (جایگزینی مدل، استریم، بودجه) روی یک API ساختگی
- تلگرام (استریم، دکمه‌ها، فوروارد، فایل، ویس، تلاش مجدد ارسال)
- API وب
- مقاوم بودن در برابر ورودی‌های نامرتب مدل (id اشتباه، «high» به جای عدد، عدد فارسی، «امشب»)، پروژه‌ها با اسم مستعار، و پیگیری استادها

## امنیت و حریم خصوصی
- همه داده‌ها روی سرور خودت در `data/peygir.db` (SQLite) می‌مانند.
- ربات تلگرام فقط به حسابی که با کد اتصال وصل شده جواب می‌دهد.
- برای اجرا روی اینترنت حتماً `APP_PASSWORD` و یک `SECRET_KEY` تصادفی بگذار و پشت HTTPS (مثلاً Caddy) اجرا کن. فایل‌های آپلودشده هم پشت همین رمز هستند.
